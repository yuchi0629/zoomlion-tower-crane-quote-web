# 中联塔机配置确认及报价单生成软件 V1.1 Web版

无需后端和数据库的静态 Web 版本。业务数据和计算规则随仓库发布，页面运行时直接读取 `public/data/app-data.json`，适合部署到 GitHub Pages。

## 内置数据

- `products.json`：269 个产品型号及产品编码、配置描述和自动识别参数
- `install-forms.json`：460 条安装形式、塔高、臂长、容绳量、钢丝绳规格、倍率和起升高度
- `price-options.json`：4301 条增减配分类、部件、物料、增减类型和价格
- `app-data.json`：网页直接使用的 267 个可见型号，按原软件规则隐藏 D、ZT 开头型号
- `lifting-performance.json`：塔机专家已确认入库的 7 款中联塔机普通/超起起重性能
- `R220-10RA(CE)`：已内嵌并发布精确匹配的详细机型配置表

数据生成严格沿用桌面版规则：增减配价格表仅录入产品组为 `B1` 的记录；产品型号与产品编码一一对应；安装参数按产品编码关联；详细配置表不进行同族型号匹配。

## 已实现功能

- 独立塔机选型模块，支持平臂/动臂和多个“幅度＋吊重”要求
- 按满足全部吊点的最小臂长匹配，逐吊点显示允许吊重、富余量和富余率
- 单个机型普通工况满足时不显示超起，普通不满足时才检查超起
- 默认显示最接近需求的前三款，按需展开全部满足机型
- 未录入详细配置表的型号仍可读取安装参数和增减配价格表
- 已发布配置表的标准配置、主要部件、选配包和包内明细
- 中文、英文、法文、德文界面及输出文件
- 当前 FOB 参考价格和增配/减配数量核算
- 单页正式版式的报价 PDF 与 LTC 选配指导 PDF
- 单工作表订单配置表，上方标准配置、下方选配配置，并只保留当前安装形式列
- Excel 保留原表合并单元格、列宽、行高、版本/发布日期，删除价格和编码
- Excel 第一行和表头使用 Arial 10 粗体，表头底色为 `#AADB1E`
- 报价单位、报价人、联系电话、邮箱、地址和商务条款本地记忆

网页不提供数据导入、审核、发布或维护入口。更新业务数据时，直接修改仓库中的 JSON 文件并重新发布。

选型性能数据来自塔机专家已确认型号库，目前包含平臂 `R90-5`、`R135-8`、`R220-10`、`R275-12`、`R335-16`、`R370-20` 和动臂 `L235-12`。未建立可追溯起重性能表的报价型号不会进入选型计算。

## 从桌面数据重新生成

在桌面项目目录中维护并发布数据后，运行：

```powershell
python tools/build_app_data.py
```

生成程序会读取桌面数据库，并用 `参考文件` 中的增减配价格表和安装参数表覆盖同编码的最新记录。随后将完整数据和已发布的精确机型配置表写入 `public/data`。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

GitHub Pages 使用仓库的 `gh-pages` 分支发布构建结果。
